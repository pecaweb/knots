📖 Guía de despliegue
Publica NudosEF en Netlify y sincroniza desde GitHub · paso a paso
1

Crear cuenta en GitHub

Ve a github.com y pulsa Sign up.

2

Crear repositorio nuevo

  • Pulsa el botón verde New.
  • Repository name:
    nudosEF
  • Visibilidad: Public
  • Activa ✔ Add a README file
  • Pulsa Create repository
3

Subir el archivo index.html

  • Add file → Upload files
  • Arrastra el archivo index.html.
  • Escribe un mensaje de commit y pulsa Commit changes
4

Actualizar en el futuro

Repite el paso 3 con la nueva versión. Netlify redesplega automáticamente.

1

Crear cuenta en Netlify

Ve a netlify.com → Sign up → Continue with GitHub (recomendado).

2

Importar proyecto

  • Add new site → Import an existing project
  • Elige GitHub y selecciona el repositorio nudosEF.
3

Configurar el despliegue

  • Branch: main
  • Build command: (dejar en blanco)
  • Publish directory: (dejar en blanco)
  • Pulsa Deploy site
4

Personalizar la URL

Site configuration → Domain management → Options → Edit site name
Ej: mis-nudos-ef.netlify.app

1

Ir a la configuración de tokens

GitHub → avatar → Settings → Developer settings → Personal access tokens → Tokens (classic).

2

Generar el token

  • Pulsa Generate new token (classic)
  • Note: NudosEF Sync
  • Activa únicamente: ✔ gist
  • Pulsa Generate token
  • ⚠️ Copia el token inmediatamente
3

Primer dispositivo

  • Ve a Sincronización → pega el token → deja el Gist vacío.
  • Pulsa Subir datos → se crea el Gist automáticamente.
  • Copia el ID del Gist que aparece en el campo.
4

Segundo dispositivo (móvil, tablet…)

  • Abre la app → Sincronización.
  • Introduce el mismo token y el ID del Gist.
  • Pulsa Guardar config y luego Descargar datos.
1

Flujo recomendado

  • Al empezar: ⬇ Descargar datos para tener la última versión.
  • Registra resultados en la Tabla de Evaluación.
  • Al acabar: ⬆ Subir datos para guardar en la nube.
2

Años académicos

  • Pulsa ＋ junto al selector de año → escribe el nombre → Crear.
  • Cada año tiene datos completamente independientes.
3

Formato del CSV de alumnos

Un nombre por línea, sin cabecera:

Ana García Martínez
Luis Pérez López
María Rodríguez Sanz
